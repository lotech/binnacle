# mockups/

HTML mockups of the dashboard layout, at the panel's real 1920x720.

- `cluster_mockup.html` — the shareable mockup. Own artwork only (no vendor assets). Three layouts (Dream / Centred / Split); the "Dream" layout = left/right info panels around a centre window (CarPlay or camera). Sample values from the live capture.

`cluster_mockup_renders.html` is the same mockup with the dash's own bundled car renders (`../app/assets/cars/`, CC BY 4.0, see the main README).

- `split_mockup.html` — the slim 640 px strip for ZLink's split mode (CarPlay 1280 px on the left or right). Own artwork; the CarPlay side is a stand-in sketch. Published as the "Model 3 Split Cluster" artifact.
